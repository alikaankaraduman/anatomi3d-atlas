# Deutsche Benennung anatomischer Strukturen (Anatomi 3D)

This guide defines how structure names are rendered in German for the Anatomi 3D atlas. The app shows
the Latin Terminologia Anatomica term as the bold title of every structure and the German name directly
below it. The target users study anatomy in German: the German line must be the name a German anatomy
textbook (Prometheus, Sobotta, Schünke) or lecturer would use next to the Latin term.

## Grundsätze

1. **Deutsche Bezeichnung, nicht das Lateinische wiederholen.** The Latin term is already shown as the
   title. Give the German name: `Musculus gluteus maximus` -> `Großer Gesäßmuskel`,
   `Arteria femoralis` -> `Oberschenkelarterie`, `Nervus medianus` -> `Mittelarmnerv`,
   `Os femoris` -> `Oberschenkelknochen`, `Ligamentum cruciatum anterius` -> `Vorderes Kreuzband`.
2. **Etablierte Namen haben Vorrang.** Use the established German name where one exists. Where German
   usage simply keeps the Latin or Greek word, that word is the German name: `Aorta`, `Pankreas`,
   `Thalamus`, `Duodenum` (with the common name in parentheses when one exists: `Duodenum (Zwölffingerdarm)`).
3. **Kein erfundener Name.** If no German name is established, build a correct descriptive German term
   from German generic nouns and the Germanised adjective, following the patterns below
   (`Ramus superficialis nervi radialis` -> `Oberflächlicher Ast des Speichennervs`). Never invent a
   colloquial name. If even that is unnatural, use the Germanised Latin form
   (`Nucleus ambiguus` -> `Nucleus ambiguus`).
4. **Bedeutung vollständig erhalten.** Every qualifier of the English and Latin name (direction, part,
   order, plural, side when it is part of the name) appears in the German name; nothing is added.
5. **Keine Seitenangabe** (rechts/links) unless the English name itself contains right/left
   (`Left ventricle` -> `Linke Herzkammer (linker Ventrikel)`). The app shows the side separately.
6. **Schreibweise.** German orthography with ä, ö, ü, ß. Nouns capitalised. The name starts with a
   capital letter, also when it starts with an adjective (`Vorderes Kreuzband`, `Tiefe Oberschenkelarterie`).
   No abbreviations (not A., V., N., M., Lig.).
7. **Zahlen und Codes** are kept: `(BIX)`, `(IV)`, `C6`. Thoracic vertebral levels are written `Th`
   in German (`T4` -> `Th4`). Ordinals are written with digits: `4. Rippe`.
8. A parenthetical alternative may be added only when it is a second genuinely common German or
   clinical name: `Mittelarmnerv (Medianus)`, `Achillessehne (Fersensehne)`.
9. Group names (kind = group) are collective and plural: `Muscles of neck` -> `Halsmuskeln`,
   `Bones of lower limb` -> `Knochen der unteren Extremität`, `Lymph nodes of neck` -> `Halslymphknoten`.
10. Names marked "(unnamed in source)" are structures whose name was lost in the source data:
    translate the note as "(in der Quelle unbenannt)".

## Hinweise aus Wikidata

The work list has a column `hint_de` with the German label and aliases of the matching Wikidata item
(matched through the TA2 identifier). Treat it as a hint, not as truth: many labels are just the Latin
term (then look for a real German name among the aliases or supply one yourself), some aliases are
obsolete, colloquial, in another language, or belong to a broader structure. Use a hint when it is the
correct German name of exactly this structure.

## Was als Fehler gilt

- A direction, side or part word dropped, added or reversed.
- The structure type changed (Arterie instead of Vene, Nerv instead of Arterie, Muskel instead of Band).
- The name of a different structure.
- An invented or wrong German name, or a colloquial name that is not established.
- The Latin term merely repeated although an established German name exists.
- Spelling or grammar errors (declension of adjectives, genitive constructions, missing umlauts or ß),
  an untranslated English word, an abbreviation.
- The same word rendered in two different ways within one file without reason.

A change that is only a stylistic preference and has no basis in this guide is not an error.
